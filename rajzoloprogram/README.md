C# Konzolos Rajzoló Projekt
-

Páros projekt a konzolos rajzolóprogram megvalósítására C#-ban.

Tagok: Jászhalmi Szabolcs és Csiha Milán Martin

Indítás és futtatás:
-
Nyissa meg a projektet a Visual Studioban, majd indítsd el a `Program.cs` fájlt. A program automatikusan beállítja a megfelelő ablakméretet.

VAGY

Nyissa meg a parancssort lépjen be abba a mappába melybe a projektet lementette, majd egy egyszerűen indítsa el a programot a - dotnet run - paranccsal

Vezérlés és billentyűparancsok:
-
* Nyilak / WASD (`y` gombbal váltató): Kurzor mozgatása
* Space: Rajzolás / Radírozás (aktuális állapottól függően)
* E: Ecset fel / le kapcsolása
* Q: Szín váltása
* C: Karakter váltása
* Backspace: Teljes rajzlap törlése
* f: Ugrás a rajzlap közepére
* r: Minta betöltése szövegesfájlból (`.txt`)
* F1 – F12: Különböző méretű és alakzatú nyomdák (X, Kereszt, Négyzet, Rombusz)
* X: Kilépés a programból
