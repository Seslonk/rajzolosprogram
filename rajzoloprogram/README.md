# C# Konzolos Rajzoló Projekt

Páros projekt a konzolos rajzolóprogram megvalósítására C#-ban.

* **Csapattagok:** Jászhalmi Szabolcs és Csiha Milán Martin

---

## Indítás és futtatás

1. **Visual Studio használatával:** Nyisd meg a projektet a Visual Studioban, majd indítsd el a `Program.cs` fájlt. A program automatikusan beállítja a megfelelő ablakméretet.
2. **Parancssorból:** Nyisd meg a parancssort, lépj be abba a mappába, ahová a projektet lementetted, majd futtasd a `dotnet run` parancsot.

---

## Vezérlés és billentyűparancsok

* **Nyilak / WASD** (`y` billentyűvel váltható): Kurzor mozgatása
* **E**: Rajzolás / Radírozás az aktuális cellán
* **Space**: Ecset fel / le kapcsolása
* **Q**: Rajzszín váltása
* **C**: Rajzkarakter váltása
* **Backspace**: Teljes rajzlap törlése
* **f**: Ugrás a rajzlap közepére
* **r**: Minta betöltése szöveges fájlból (`.txt`)
* **F1 – F12**: Különböző méretű és alakzatú nyomdák (X, Kereszt, Négyzet, Rombusz)
* **X**: Kilépés a programból
